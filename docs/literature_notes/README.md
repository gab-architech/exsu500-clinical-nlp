# Literature notes

One file per paper, named `YYYY_firstauthor_keyword.md` (e.g. `2026_barman_clignet.md`).

Course rule: every reference we cite must have been read by at least one team member, and the instructors ask about specific citations. Write the note after reading the paper, not from its abstract alone.

## Template

Copy this into a new file:

```markdown
# [Short title]

- **Citation:** Authors, "Title," Venue, Year. DOI or arXiv ID.
- **Read by:** [name], [date]
- **Peer-reviewed?** yes / no (preprint)

**What they did:** dataset, task, methods (2 to 3 sentences).

**Main result:** the key number(s), with the metric named.

**Limitation:** the main weakness or caveat.

**Relevance to our project:** how it supports or challenges our task, data handling, models or evaluation.
```
